# Framework development

## Goal and scope

- **Goal**: This project is an **opinionated Expo(react native) based mobile framework**: make it easy to start a new project. it is expected to be used as a package, not copied.
- **Scope**: common features needed for a mobile app .
- **Out of scope** (add per project, keep the core lean): businees logics.
