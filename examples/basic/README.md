# Basic Example

The smallest consumer of the runtime package is the project generated by `create-denebola`:

```sh
pnpm create create-denebola my-app
cd my-app && pnpm install && pnpm dev
```

A business screen uses the package's primitives and NativeWind tokens:

```tsx
// src/app/index.tsx
import { Card, Screen, Text } from "denebola";

export default function HomeScreen() {
  return (
    <Screen>
      <Text className="text-4xl font-extrabold">Hello</Text>
      <Card>
        <Text>Business screens live under src/app.</Text>
      </Card>
    </Screen>
  );
}
```

The full walkthrough — root layout, config plugin, providers, i18n, deep links, doctor and update flow — is in `examples/consumer/README.md`.
